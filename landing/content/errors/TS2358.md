---
code: TS2358
summary: The left side of `instanceof` is a primitive type, which is never an instance. Use `typeof` for primitives.
---

## What it means

`x instanceof C` checks an object's prototype chain. When `x` is typed as a primitive such as
`string` or `number`, the test can't succeed.

## Example

```ts example
const value = "text";

export const isString = value instanceof String;
```

## How to fix

- Use `typeof value === "string"` for primitives.
