## What it means

A subclass's fields aren't initialised until the base constructor returns, so a base constructor that calls a method a subclass can override (or passes `this` out) can run subclass code on a half-built object. `#private` and `private` members are allowed, because their bodies are checked by the same rule.

## Example

```ts spec
// A base constructor calls a method a subclass can override.
class Base {
  constructor() {
    this.setup(); // @expect TSR0803
  }
  setup(): void {
    console.log("base");
  }
}
new Base();
export {};
```

## How to fix

- Make the helper `#private`.
- Replace two-phase initialisation with a static factory that constructs, then calls the setup method.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
