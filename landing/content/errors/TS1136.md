---
code: TS1136
summary: Inside an object literal, the parser expected a property (`name: value`, a method or a spread) but found another token.
---

## What it means

An object literal contains properties, shorthand properties, methods, accessors and `...`
spreads, separated by commas. This is reported when an entry starts with a token that can't
begin any of these. It's also reported by ts-r's `tsconfig.json` reader for malformed JSON
objects.

## Example

```ts example
export const o = { a: 1, + };
```

## How to fix

- Remove the stray token or finish the property: `{ a: 1, b: 2 }`.
