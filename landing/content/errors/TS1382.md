---
code: TS1382
summary: A `>` appears in JSX text. Write `{'>'}` or `&gt;` to show the character, or check for a malformed tag.
---

## What it means

A bare `>` in JSX text is not allowed; it often means a tag was closed twice or an attribute
was written wrongly. To show the character itself, it has to be escaped.

## Example

```tsx example
export const a = <div>></div>;
```

```json tsconfig
{"compilerOptions": {"jsx": "preserve"}}
```

## How to fix

- Fix the tag if the `>` is a typo.
- To display it, write `{'>'}` or `&gt;`.
