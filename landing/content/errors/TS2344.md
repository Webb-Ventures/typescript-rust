---
code: TS2344
summary: A type argument doesn't meet the constraint of the type parameter it fills (`T extends ...`). Pass a type that satisfies it.
---

## What it means

A type parameter declared as `T extends C` only accepts type arguments assignable to `C`.
Giving it a type that isn't is reported at the type argument.

## Example

```ts example
type Keys<T extends object> = keyof T;

export type K = Keys<string>;
```

## How to fix

- Pass a type that satisfies the constraint.
- If the constraint is too strict, relax it in the declaration.
