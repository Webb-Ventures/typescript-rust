---
code: TS1244
summary: An abstract method is declared in a class that isn't abstract. Mark the class `abstract`, or give the method a body.
---

## What it means

An `abstract` method has no body, so only an `abstract` class, which can't be instantiated,
may declare one. A plain class with an abstract method is reported here.

## Example

```ts example
export class Shape {
  abstract area(): number;
}
```

## How to fix

- Make the class abstract: `abstract class Shape`.
- Or implement the method and drop `abstract`.
