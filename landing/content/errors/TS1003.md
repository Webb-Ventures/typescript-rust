---
code: TS1003
summary: The parser expected a name (an identifier) here but found something else, such as a punctuation mark or the end of the statement.
---

## What it means

A name is required at this point: after a `.` in a property access, after keywords such as
`class` or `function` in a declaration, or in a parameter or variable list. Often the code is
unfinished, or a reserved word or symbol is in the place of the name.

## Example

```ts example
const obj = { a: 1 };
const v = obj.;
export {};
```

## How to fix

- Finish the expression or declaration with a name: `obj.a`.
- If the name is a reserved word, rename it, or use bracket access (`obj["default"]`).
- Remove a stray `.` or `,` left over from an edit.
