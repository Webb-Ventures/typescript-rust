---
code: TS2403
summary: The same var or declared variable is declared again with a different type. Use one type for every declaration, or rename one of them.
---

## What it means

`var` declarations, and variables merged from several declaration files, all declare the same
variable. Each declaration must state the same type; a later one with a different type is
reported.

## Example

```ts example
export {};
var limit: number;
var limit: string;
```

## How to fix

- Give every declaration of the variable the same type.
- Rename one of them if they are really different variables.
- Use `let` or `const`, which can't be redeclared at all, for new code.
