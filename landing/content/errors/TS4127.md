---
code: TS4127
summary: A member with a computed (dynamic) name has the override modifier. Remove override, or use a literal name.
---

## What it means

The checker can't tell which base class member a computed name like `[key]` refers to, so it
doesn't allow `override` on it.

## Example

```ts example
const key: string = "run";
class Base {}
class Child extends Base {
  override [key]() {}
}
export {};
```

## How to fix

- Remove `override` from the member.
- Or use a literal name so the override can be checked.
