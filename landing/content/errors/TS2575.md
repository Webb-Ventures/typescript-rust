---
code: TS2575
summary: A call passes an argument count that no overload accepts, though overloads exist for counts on either side. Pass the number one overload expects.
---

## What it means

The function has several overload signatures, and the call passes a number of arguments that
falls between the counts they accept. For example, overloads for 1 and 3 arguments, called with 2.

## Example

```ts example
function pick(a: string): string;
function pick(a: string, b: string, c: string): string;
function pick(a: string, b?: string, c?: string): string { return a + (b ?? "") + (c ?? ""); }
pick("x", "y");
export {};
```

## How to fix

- Pass the number of arguments one of the overloads expects.
- If the in-between count should be allowed, add an overload signature for it.
