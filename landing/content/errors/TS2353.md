---
code: TS2353
summary: An object literal has a property its target type doesn't declare (an excess property). Remove it, fix its spelling, or add it to the type.
---

## What it means

Object literals assigned directly to a typed target are checked for extra properties.
Properties the target type doesn't know about are usually typos or leftovers.

## Example

```ts example
interface Options {
  verbose?: boolean;
}

export const o: Options = { colour: true };
```

## How to fix

- Fix the spelling or remove the property. (When the name is close to a known property, the
  error is TS2561, which suggests it.)
- Add the property to the type if it belongs there.
