---
code: TS2394
summary: An overload signature accepts or returns something its implementation signature does not. Make the implementation cover every overload.
---

## What it means

Every overload has to be compatible with the implementation that follows: the implementation's
parameters must accept the overload's arguments, and its return type must fit the overload's
return type. It's reported on the first overload that doesn't fit.

## Example

```ts example
export function pad(value: string): string;
export function pad(value: number): string;
export function pad(value: string): string {
  return value.padStart(4);
}
```

## How to fix

- Widen the implementation's parameters to cover every overload (here `value: string | number`).
- Remove the overload if the implementation was never meant to handle it.
