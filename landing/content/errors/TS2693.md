---
code: TS2693
summary: A name that only exists as a type (interface or type alias) is used as a value. Use a real value, or compare against something that exists at runtime.
---

## What it means

Interfaces and type aliases are erased when TypeScript is compiled, so there is nothing to refer
to at runtime. Using one in an expression, such as calling it or passing it to `instanceof`, is
an error.

## Example

```ts example
interface User { name: string }
const u = User;
export {};
```

## How to fix

- If you need a runtime value, declare a class or a constant instead of (or alongside) the type.
- For runtime type checks, test the shape: `typeof x.name === "string"`, or use a validator.
