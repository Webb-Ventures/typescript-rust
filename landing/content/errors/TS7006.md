---
code: TS7006
summary: A function parameter has no type annotation and nothing gives it a type, so it would be `any`. Annotate the parameter.
---

## What it means

Under `noImplicitAny` (part of `strict`), a parameter without a type annotation, default value
or contextual type would silently be `any`. Callbacks passed to typed functions get their
parameter types from context, so this mostly shows up on standalone functions and on
callbacks passed to values typed `any`.

## Example

```ts example
export function double(n) {
  return n * 2;
}
```

## How to fix

- Add a type annotation: `function double(n: number)`.
- Give the parameter a default value, which also gives it a type.
- If the function is a callback, type the thing it is passed to so the parameter gets a
  contextual type.
