---
code: TS1381
summary: A `}` appears in JSX text. Write `{'}'}` or `&rbrace;` to show the character, or remove the stray brace.
---

## What it means

In JSX text, `{` and `}` delimit expressions. A lone `}` in text is usually a leftover brace
from editing, and is a syntax error. To show the character itself, it has to be escaped.

## Example

```tsx example
export const a = <div>}</div>;
```

```json tsconfig
{"compilerOptions": {"jsx": "preserve"}}
```

## How to fix

- Remove the stray brace if it's a typo.
- To display it, write `{'}'}` or `&rbrace;`.
