---
code: TS1100
summary: `eval` or `arguments` is used as a name in strict-mode code. Rename the variable, parameter or function.
---

## What it means

In strict mode, `eval` and `arguments` can't be declared or assigned: not as a variable,
function, parameter or catch binding. This code is reported in scripts with a `"use strict"`
directive. Modules and classes are always strict, and report the same mistake as
[TS1215](TS1215.md) and [TS1210](TS1210.md).

## Example

```ts example
"use strict";
var arguments = 1;
```

## How to fix

- Rename the binding, for example `args` or `evaluate`.
- To read all arguments of a function, use a rest parameter: `function f(...args: unknown[])`.
