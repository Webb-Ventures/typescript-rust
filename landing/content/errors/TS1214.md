---
code: TS1214
summary: A word reserved in strict mode (such as `let`, `static` or `yield`) is used as a name in a module. Pick another name.
---

## What it means

Modules always run in strict mode, and strict mode reserves a few extra words: `implements`,
`interface`, `let`, `package`, `private`, `protected`, `public`, `static` and `yield`. Using one
of them as a variable, function or parameter name in a file with `import` or `export` is
reported here.

## Example

```ts example
export {};
const yield = 1;
```

## How to fix

- Rename the binding, for example `yieldValue` instead of `yield`.
