---
code: TS7026
summary: JSX is used but no `JSX.IntrinsicElements` type is declared, usually because React's types aren't installed or `jsx` isn't set.
---

## What it means

To type-check JSX, the checker looks for a global `JSX` namespace (or the one from the
`jsxImportSource` package) with interfaces such as `IntrinsicElements`. When it doesn't exist,
every JSX element would be `any` and this is reported for each element. It usually means the
React types (or your framework's JSX types) aren't installed or aren't reachable from the
project.

## Example

```tsx example
export const el = <div>hello</div>;
```

## How to fix

- Install the types for your JSX runtime, for example `npm i -D @types/react`.
- Check that `jsx` and `jsxImportSource` in tsconfig.json point at that runtime.
