---
code: TS5076
summary: Two operators like `??` and `||` are mixed without parentheses. Add parentheses to say which runs first.
---

## What it means

`??` can't be combined directly with `||` or `&&` in the same expression. The order of
evaluation would be ambiguous to a reader, so the grammar requires parentheses around one side.
ts-r's parser reports this as a syntax error.

## Example

```ts example
declare const a: string | undefined;
declare const b: boolean;
export const value = a ?? b || "default";
```

## How to fix

- Add parentheses around the part that should run first: `(a ?? b) || "default"` or
  `a ?? (b || "default")`.
