---
code: TS18013
summary: A `#private` class member is used outside the class that declares it. Use it inside the class, or expose a method.
---

## What it means

Members whose names start with `#` are private at runtime and in the type system: only code
inside the class body that declares them can read or write them. Accessing one from outside
(including from a subclass) is reported with this code.

## Example

```ts example
class Counter {
  #count = 0;
}
export function peek(c: Counter) {
  return c.#count;
}
```

## How to fix

- Move the code that needs the member into the class.
- Add a public method or getter that returns what callers need.
