---
code: TS5090
summary: A `paths` substitution in tsconfig.json is a bare path. Start it with `./` so it is relative to the config file.
---

## What it means

Every substitution in `compilerOptions.paths` must be a relative path (starting with `./` or
`../`), an absolute path, or start with `${configDir}`. Since `baseUrl` was removed, a bare
`src/*` has nothing to be resolved against. The error is reported on the substitution in
`tsconfig.json`.

## Example

```json tsconfig
{ "compilerOptions": { "paths": { "@/*": ["src/*"] } } }
```

```ts example
export const x = 1;
```

## How to fix

- Prefix the substitution with `./`: `"@/*": ["./src/*"]`. It is resolved relative to the
  tsconfig.json that declares it.
