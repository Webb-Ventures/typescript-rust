---
code: TS2362
summary: The left operand of `-`, `*`, `/`, `%` or `**` isn't a number, bigint or enum. Convert it first.
---

## What it means

Arithmetic operators other than `+` need numeric operands. A string, boolean, object or
`Date` on the left is reported.

## Example

```ts example
const start = new Date();

export const elapsed = start - 1;
```

## How to fix

- Convert explicitly: `start.getTime() - 1`, `Number(text) * 2`.
