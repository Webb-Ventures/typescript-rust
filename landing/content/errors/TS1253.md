---
code: TS1253
summary: An abstract property is declared in a class that isn't abstract. Mark the class `abstract`, or give the property a value.
---

## What it means

Like abstract methods, `abstract` properties are only allowed in an `abstract` class, since
something must subclass it and provide the value.

## Example

```ts example
export class Config {
  abstract name: string;
}
```

## How to fix

- Mark the class `abstract`.
- Or remove `abstract` and initialise the property.
