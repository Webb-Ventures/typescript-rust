---
code: TS1110
summary: The parser expected a type here but found something else, for example after `:` in an annotation or inside type arguments.
---

## What it means

After `:` in an annotation, after `as`, inside `<...>` type arguments and in a type alias, a
type is required. This is reported when that position is empty or holds a token that can't
start a type.

## Example

```ts example
let value: = 1;
export {};
```

## How to fix

- Write the type: `let value: number = 1;`.
- If you want the type inferred, remove the `:` as well.
