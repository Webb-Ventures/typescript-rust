---
code: TS2304
summary: A name is used that isn't declared anywhere the checker can see: a typo, a missing import, or a missing type package such as @types/node.
---

## What it means

The identifier doesn't resolve to any variable, function, class, type or namespace in scope,
in the file's imports, or in the global declarations of the lib files and type packages the
project includes.

## Example

```ts example
export const total = subtotal + 1;
```

## How to fix

- Fix the spelling, or declare the name.
- Import it if it lives in another module.
- For globals such as `process` or `describe`, install the type package (`@types/node`,
  your test framework's types) and check `types` in tsconfig.json.
