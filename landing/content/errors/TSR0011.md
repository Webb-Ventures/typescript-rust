## What it means

Each sound-mode level forces the `strict` family of options for its files. When the tsconfig doesn't set the option named in `{1}` and only sound mode turns it on, tsc's diagnostic is reported with this TSR code and tsc's message in `{0}`. If the tsconfig already sets the option, tsc's own code is reported instead.

## How to fix

- Fix what the wrapped tsc message describes.
- Or turn the option on in tsconfig.json, so the error keeps tsc's code and tsc reports it too.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
