---
code: TS2339
summary: A property is read on a type that doesn't declare it. Check the spelling, narrow a union first, or add the property to the type.
---

## What it means

The type of the expression before the `.` has no member with that name. On a union, the
property must exist on every member. Values typed `{}` or `object` have no properties.

## Example

```ts example
const user = { name: "Ada" };

export const email = user.email;
```

## How to fix

- Fix the spelling, or add the property to the type.
- For a union, narrow first (`if ("email" in user)`, a discriminant check, or `typeof`).
- For data from outside the program, declare its type and validate it.
