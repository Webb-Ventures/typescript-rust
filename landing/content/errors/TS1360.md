---
code: TS1360
summary: An expression doesn't match the type given with `satisfies`. Change the value, or the type it must satisfy.
---

## What it means

`expr satisfies T` checks that the expression is assignable to `T` without changing the
expression's own type. When it isn't, this error is reported at the expression.

## Example

```ts example
type Color = "red" | "green";

export const theme = { primary: "blue" } satisfies Record<string, Color>;
```

## How to fix

- Fix the value so it fits the type.
- If the type is too narrow, widen it.
