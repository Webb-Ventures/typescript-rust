---
code: TS1029
summary: Two modifiers are written in the wrong order. Swap them so the first one named in the message comes first.
---

## What it means

Modifiers on class members have a fixed order: accessibility (`public`, `private`,
`protected`) comes before `static`, `override`, `readonly` and `accessor`, for example. The
message names both modifiers and which one must come first.

## Example

```ts example
export class User {
  static public count = 0;
}
```

## How to fix

- Reorder the modifiers as the message says: `public static count = 0`.
