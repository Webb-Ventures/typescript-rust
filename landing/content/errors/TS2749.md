---
code: TS2749
summary: A variable or function is used in a type position. Use typeof name to get its type, or reference the actual type.
---

## What it means

Values and types live in separate namespaces. A name that is only a value (a variable, a
function, a constant) can't be used as a type directly.

## Example

```ts example
const defaults = { port: 80 };
let config: defaults;
export {};
```

## How to fix

- Use `typeof` to get the value's type: `let config: typeof defaults;`.
- Or declare a named type or interface and use that.
