---
code: TS2694
summary: A qualified name like Ns.Member refers to a member the namespace doesn't export. Check the spelling, or export the member.
---

## What it means

In a qualified type or value name such as `Ns.Member`, the namespace exists but has no exported
member with that name. Members of a namespace that aren't `export`ed aren't visible outside it.

## Example

```ts example
namespace Shapes {
  export interface Circle { r: number }
}
let s: Shapes.Square;
export {};
```

## How to fix

- Fix the member name.
- Add `export` to the member inside the namespace.
- If the namespace comes from a package, check that the version you have installed declares it.
