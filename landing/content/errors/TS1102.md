---
code: TS1102
summary: `delete` is applied to a plain variable name in strict-mode code. Delete object properties only; set variables to `undefined` instead.
---

## What it means

In strict mode, `delete` can only remove properties (`delete obj.key`). Deleting a variable
name is an error. `ts-r-check` also reports [TS2703](TS2703.md) for the same expression,
because the operand isn't a property reference.

## Example

```ts example
let x = 1;
delete x;
export {};
```

## How to fix

- To clear a variable, assign `undefined` or `null` to it.
- If the value is a property, delete the property: `delete obj.x`.
