---
code: TS1210
summary: `eval` or `arguments` is declared or assigned inside a class. Class bodies are strict-mode code, which forbids this. Rename it.
---

## What it means

Code in a class body (methods, constructors, accessors, field initialisers) always runs in
strict mode, where `eval` and `arguments` can't be used as names for variables, parameters or
functions.

## Example

```ts example
export class A {
  m() {
    var arguments = 1;
  }
}
```

## How to fix

- Rename the binding, for example `args`.
- To collect all arguments, use a rest parameter: `m(...args: unknown[])`.
