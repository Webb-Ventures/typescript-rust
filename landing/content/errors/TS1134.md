---
code: TS1134
summary: After `var`, `let` or `const`, the parser expected a variable name or destructuring pattern but found something else.
---

## What it means

A variable statement needs at least one declaration: a name or a `{...}` / `[...]` pattern.
This is reported when the keyword is followed by `;`, a number, or another token that can't be
a name.

## Example

```ts example
var ;
export {};
```

## How to fix

- Add the variable name: `var count;`.
- Names can't start with a digit: `const x1 = 1`, not `const 1x = 1`.
