---
code: TS1351
summary: A letter or keyword follows a number with no space, like `3in` or `1px`. Add a space or an operator, or quote the text.
---

## What it means

A numeric literal must end before the next identifier or keyword starts. Text such as
`10px` or `3in` is read as a number immediately followed by a name, which is a syntax
error.

## Example

```ts example
export const width = 10px;
```

## How to fix

- Make it a string if it's a CSS-style value: `"10px"`.
- Add the missing operator or space if two tokens were meant.
