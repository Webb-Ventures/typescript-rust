---
code: TS2384
summary: Some overload signatures of a function are `declare`d (ambient) and others aren't. Make them all the same.
---

## What it means

All overloads of a function must agree on `declare`: either they all describe a function
implemented elsewhere, or they are all part of this file's implementation.

## Example

```ts example
declare function parse(s: string): number;
function parse(s: number): number;
function parse(s: string | number): number {
  return Number(s);
}
export { parse };
```

## How to fix

- Remove `declare` from the overloads that have an implementation here, or add it to all of
  them (and remove the body).
