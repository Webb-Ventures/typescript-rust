---
code: TS2741
summary: An object lacks one required property of the target type. Add the property, or make it optional in the type.
---

## What it means

The value is assigned to a type that requires a property it doesn't have. For several missing
properties the checker uses [TS2739](TS2739.md) instead.

## Example

```ts example
interface User { id: number; name: string }
const u: User = { id: 1 };
export {};
```

## How to fix

- Add the property to the value.
- Mark it optional in the type (`name?: string`) if it can be absent.
