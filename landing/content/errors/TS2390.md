---
code: TS2390
summary: A class declares constructor overloads but no constructor with a body. Add the implementation after the overload signatures.
---

## What it means

Constructor overload signatures only describe how the class can be constructed. A class that
isn't `declare`d or abstract-only still needs one constructor with a body that handles every
overload.

## Example

```ts example
export class Point {
  constructor(x: number, y: number);
  constructor(xy: [number, number]);
}
```

## How to fix

- Add a constructor with a body after the overloads, with parameters that accept every overload.
- If the class only describes an existing value, use a `declare class` in a `.d.ts` file.
