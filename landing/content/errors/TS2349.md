---
code: TS2349
summary: A value is called with `()` but its type has no call signature. Check that it's really a function.
---

## What it means

The expression's type has no call signatures, so it can't be called. Common causes are
calling a property that is a value, an object, or a union where some members aren't
callable.

## Example

```ts example
const settings = { theme: "dark" };

export const t = settings.theme();
```

## How to fix

- Remove the call if the value isn't a function.
- For a union, narrow to the callable member first (`typeof x === "function"`).
