---
code: TS2315
summary: Type arguments are given to a type that has no type parameters. Remove them, or make the type generic.
---

## What it means

Only generic types accept `<...>` arguments. Writing `User<string>` when `User` declares no
type parameters is reported here.

## Example

```ts example
interface User {
  name: string;
}

export const u: User<string> = { name: "a" };
```

## How to fix

- Remove the type arguments.
- Or add a type parameter to the declaration if it should be generic.
