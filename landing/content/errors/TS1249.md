---
code: TS1249
summary: A decorator is on an overload signature instead of the method implementation. Move it to the implementation.
---

## What it means

Overload signatures have no runtime code, so they can't be decorated. Only the
implementation, the declaration with a body, can carry decorators.

## Example

```ts example
function log(target: unknown, context: ClassMethodDecoratorContext) {}

export class Api {
  @log
  get(id: number): string;
  get(id: string): string;
  get(id: number | string): string {
    return String(id);
  }
}
```

## How to fix

- Put the decorator on the implementation signature (the one with the body).
