---
code: TS1101
summary: A `with` statement is used in strict-mode code, which includes every module and class. Replace it with explicit property access.
---

## What it means

`with` adds an object's properties to the scope. It's forbidden in strict mode, and modules
and classes are always strict, so in practice it's an error in almost all TypeScript code.

## Example

```ts example
const o = { a: 1 };
with (o) {}
export {};
```

## How to fix

- Read the properties explicitly: `o.a`.
- Use destructuring to get short names: `const { a } = o;`.
