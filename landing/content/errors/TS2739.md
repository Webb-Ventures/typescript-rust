---
code: TS2739
summary: An object is missing several required properties of the target type (the message lists them). Add the properties or make them optional.
---

## What it means

The value is assigned to a type that requires properties it doesn't have. The message lists the
missing ones. With one missing property the checker uses [TS2741](TS2741.md); with many, it lists
a few and counts the rest ([TS2740](TS2740.md)).

## Example

```ts example
interface Point { x: number; y: number; z: number }
const p: Point = { x: 1 };
export {};
```

## How to fix

- Add the missing properties to the value.
- Mark them optional in the type (`y?: number`) if they really are.
