---
code: TS7010
summary: A declaration without a body (overload, interface method, `declare function`) has no return type, so it would return `any`. Add one.
---

## What it means

Under `noImplicitAny`, a function or method declaration with no body has nothing to infer a
return type from. Without an annotation its return type is `any`. ts-r reports this for
body-less declarations such as `declare function`, overload signatures and methods in
interfaces or ambient classes.

## Example

```ts example
declare function load(path: string);
export const data = load("a.json");
```

## How to fix

- Write the return type: `declare function load(path: string): unknown;`.
