---
code: TS2351
summary: `new` is used on a value that has no construct signature. Make sure it's a class or constructor.
---

## What it means

`new X()` needs `X` to have a construct signature, such as a class. Using `new` on an object,
an instance or another value without one is reported here, with a second line naming the
type. (With `noImplicitAny`, `new` on a plain function expression is reported as TS7009
instead.)

## Example

```ts example
const settings = { theme: "dark" };

export const s = new settings();
```

## How to fix

- Call it without `new` if it's a plain function.
- Use a class if you need instances.
