---
code: TS2559
summary: A value is assigned to a type whose properties are all optional, but the value has none of them. Check you passed the right object.
---

## What it means

A type whose properties are all optional (a "weak" type) would accept almost anything. To catch
mistakes, assigning a value that shares no property with it is reported.

## Example

```ts example
interface Options {
  verbose?: boolean;
  depth?: number;
}
const opts = { colour: true };
export const o: Options = opts;
```

## How to fix

- Pass an object with at least one of the expected properties (often a typo in a property name).
- If the value really is unrelated, don't assign it to that type.
