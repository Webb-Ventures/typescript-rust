---
code: TS2385
summary: All overloads of a method must have the same accessibility. Give every overload and the implementation the same public, private or protected modifier.
---

## What it means

Overload signatures of a class method and its implementation form one member, so they must
agree on accessibility. Mixing `public`, `private` and `protected` across the signatures of the
same method is reported on the signature that differs from the first.

## Example

```ts example
export class Parser {
  public parse(text: string): string;
  private parse(text: string, strict: boolean): string;
  public parse(text: string, strict?: boolean): string {
    return strict ? text.trim() : text;
  }
}
```

## How to fix

- Use the same modifier on every overload and on the implementation.
- If one form should stay private, give it its own method name instead of an overload.
