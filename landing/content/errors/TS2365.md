---
code: TS2365
summary: A binary operator is used on two types it doesn't work with, like `+` on a number and an object, or `<` on a number and a string.
---

## What it means

Operators such as `+`, `<`, `>`, `<=` and `>=` accept only some combinations of operand
types. The message names the operator and both types.

## Example

```ts example
const a = 1;
const b = { value: 2 };

export const c = a + b;
```

## How to fix

- Use the property you meant (`a + b.value`), or convert the operands so both are numbers
  (or both strings).
