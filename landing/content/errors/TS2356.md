---
code: TS2356
summary: `++`, `--`, unary `-` or `~` is applied to a value that isn't a number, bigint or enum. Convert it first.
---

## What it means

Arithmetic unary operators need a numeric operand. Applying them to a string, boolean or
object is reported.

## Example

```ts example
let label = "1";
label++;
export { label };
```

## How to fix

- Convert the value to a number first, or keep a separate numeric variable.
