---
code: TS1124
summary: A number literal ends where a digit is required, for example after the `e` of an exponent. Add the digits.
---

## What it means

Some parts of a number literal must be followed by at least one digit: the exponent marker
`e` (or `E`, with an optional sign) is the usual case.

## Example

```ts example
const n = 1e;
export {};
```

## How to fix

- Add the exponent digits: `1e3`.
- If `e` wasn't meant to be part of the number, separate it: `1 * e`.
