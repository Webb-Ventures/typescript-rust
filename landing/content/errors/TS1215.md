---
code: TS1215
summary: `arguments` or `eval` is declared or assigned in a module, which strict mode forbids. Use a different name.
---

## What it means

In strict mode, which every module is in, `eval` and `arguments` can't be declared, assigned
or used as parameter names. A file with `import` or `export` is a module, so such a use is
reported here.

## Example

```ts example
export {};
let eval = 1;
```

## How to fix

- Rename the variable or parameter.
- Use rest parameters (`...args`) instead of assigning to `arguments`.
