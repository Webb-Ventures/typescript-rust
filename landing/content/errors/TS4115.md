---
code: TS4115
summary: Under noImplicitOverride, a constructor parameter property replaces a base class member without override. Add override to it.
---

## What it means

A parameter property (`constructor(public x: T)`) declares a class member. With
`noImplicitOverride` on, if a base class already has that member, the parameter property needs
`override` too.

## Example

```json tsconfig
{ "compilerOptions": { "noImplicitOverride": true } }
```

```ts example
class Base {
  name = "";
}
class Child extends Base {
  constructor(public name: string) { super(); }
}
export {};
```

## How to fix

- Add `override` to the parameter: `constructor(public override name: string)`.
