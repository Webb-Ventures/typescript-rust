---
code: TS6053
summary: A file named in tsconfig.json (an `extends` target or a project reference) doesn't exist. Fix the path or install the package.
---

## What it means

The config points at a file that can't be found. ts-r reports this for an `extends` entry that
names a package config which isn't installed (`@tsconfig/node22/tsconfig.json` is looked up in
`node_modules`) and for a `references` entry whose path has no tsconfig.json. A relative
`extends` path to a missing file is reported as `Cannot read file` (TS5083) instead.

## Example

```json tsconfig
{ "extends": "@tsconfig/strictest/tsconfig.json" }
```

```ts example
export const x = 1;
```

## How to fix

- Install the package that provides the `extends` target, or correct its name.
- Correct a `references` path; it is relative to the tsconfig.json that contains it.
