## What it means

Sound mode is configured in one of three places: the `[sound]` table of `ts-r.toml`, a `tsrconfig.json` (`{ "sound": { ... } }`, comments allowed), or a top-level `"ts-r": { "sound": { ... } }` key in tsconfig.json. A problem with that configuration (an unknown key, a value of the wrong type, a malformed `refinements` entry) is reported on the file, with the details in `{0}`.

Configuring sound mode in more than one of those places is one such problem. The message names every file involved, for example `sound mode is configured in more than one place: the "ts-r" key of 'tsconfig.json' and 'ts-r.toml'; keep one`.

## How to fix

- Keep the configuration in one place: `ts-r.toml`, `tsrconfig.json` or the `"ts-r"` key of tsconfig.json.
- Check the values against the configuration section of [design record 0007](../../../docs/design/0007-sound-mode.md).

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
