## What it means

An escape hatch that suppresses nothing is reported so hatches can't outlive the code they excuse. A hatch with its own error ([TSR0001](TSR0001.md) or [TSR0003](TSR0003.md)) suppresses nothing and isn't also reported as unused.

## Example

```ts spec
// A hatch on a line with no sound-mode error.
// @ts-r-unsafe S-03: kept from an old version of this code. // @expect TSR0002
const n: number = 1;
export { n };
```

## How to fix

- Delete the directive.
- If the error it was for moved, move the directive to the line before it.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
