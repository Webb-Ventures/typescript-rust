---
code: TS2430
summary: An interface extends another but redeclares a member with an incompatible type. Make the member's type assignable to the base interface's.
---

## What it means

An interface that extends another must stay assignable to it. Redeclaring an inherited property
with a type that doesn't fit the base property's type is reported on the interface name.

## Example

```ts example
interface Entity {
  id: string;
}
export interface Order extends Entity {
  id: number;
}
```

## How to fix

- Use a type for the member that is assignable to the base one (the same type, or a narrower one).
- If the member needs a different type, use `Omit<Entity, "id">` as the base, or rename the member.
