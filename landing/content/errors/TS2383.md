---
code: TS2383
summary: Some overload signatures of a function are exported and others aren't. Export all of them, or none.
---

## What it means

All overloads of a function, and its implementation, form one declaration. They must agree
on `export`.

## Example

```ts example
export function parse(s: string): number;
function parse(s: number): number;
export function parse(s: string | number): number {
  return Number(s);
}
```

## How to fix

- Add or remove `export` so every signature matches.
