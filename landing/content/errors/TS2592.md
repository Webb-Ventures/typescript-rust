---
code: TS2592
summary: jQuery's $ or jQuery global is used without its type definitions. Install @types/jquery and add "jquery" to the types option.
---

## What it means

The name is jQuery's global (`$` or `jQuery`), and no jQuery type definitions are loaded.

## Example

```ts example
$(".item");
export {};
```

## How to fix

- Install the type definitions: `npm i --save-dev @types/jquery`.
- If `tsconfig.json` sets `types`, add `"jquery"` to it.
- Or import jQuery as a module instead of relying on the global.
