---
code: TS7013
summary: A construct signature (`new (...)`) in a type has no return type, so it would return `any`. Add one.
---

## What it means

Under `noImplicitAny`, a `new (...)` signature in an interface or type literal must say what it
constructs. Without an annotation the constructed value is `any`.

## Example

```ts example
export interface Factory {
  new (name: string);
}
```

## How to fix

- Add the instance type: `new (name: string): User;`.
