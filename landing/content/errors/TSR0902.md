## What it means

A narrowing of a local `let`, `var` or parameter that is assigned inside another function or class body is dropped at every call, `await` and `yield`, because that call can run the closure. Locals never assigned from a closure keep TypeScript's behaviour.

## Example

```ts spec
// A let assigned inside a closure can change when the closure runs.
function run(): number {
  let cur: string | null = Math.random() > 0.5 ? "a" : null;
  const reset = (): void => {
    cur = null;
  };
  if (cur !== null) {
    reset();
    return cur.length; // @expect TSR0902
  }
  return 0;
}
export const n: number = run();
```

## How to fix

- Copy the variable to a `const` before the call and use the copy.
- Or restructure so the closure doesn't assign the variable.
