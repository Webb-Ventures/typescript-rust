---
code: TS7032
summary: A `set` accessor's parameter has no type and there's no `get` to infer it from, so the property would be `any`. Annotate the parameter.
---

## What it means

Under `noImplicitAny`, a property defined only by a setter takes its type from the setter's
parameter. Without an annotation (and without a matching getter whose return type could be
used) the property would be implicitly `any`.

## Example

```ts example
export class Box {
  set value(v) {}
}
```

## How to fix

- Annotate the parameter: `set value(v: number) {}`.
- Or add a getter with a return type that the setter's parameter can take.
