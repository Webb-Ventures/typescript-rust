---
code: TS4112
summary: A member has the override modifier but its class doesn't extend another class. Remove override, or add the missing extends.
---

## What it means

`override` says the member replaces one from a base class. A class with no `extends` clause has
no base class, so nothing can be overridden.

## Example

```ts example
class Logger {
  override log() {}
}
export {};
```

## How to fix

- Remove `override`.
- Or add the `extends` clause you meant to write.
