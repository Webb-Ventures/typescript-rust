---
code: TS2388
summary: Overloads of a class method mix static and instance signatures. Remove static from the overload, or make the whole member static.
---

## What it means

This is the counterpart of [TS2387](TS2387.md): the first signature for the name is an
instance method, and a later signature or the implementation is marked `static`.

## Example

```ts example
export class Ids {
  next(prefix: string): string;
  static next(prefix: string): string {
    return prefix + "1";
  }
}
```

## How to fix

- Remove `static` so every signature and the implementation are instance methods.
- Or make all of them `static`, if the method doesn't use `this`.
