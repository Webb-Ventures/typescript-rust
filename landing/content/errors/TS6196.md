---
code: TS6196
summary: A type, interface, class or type parameter is declared but never used. Remove it or use it.
---

## What it means

With `noUnusedLocals` on, declarations that are only types (type aliases, interfaces) and
local classes that are never referenced are reported with this code; [TS6133](TS6133.md) covers
values that are never read. Unused type parameters are reported under `noUnusedParameters`.

## Example

```json tsconfig
{ "compilerOptions": { "noUnusedLocals": true } }
```

```ts example
interface Draft {
  title: string;
}
export const x = 1;
```

## How to fix

- Delete the unused declaration.
- If it's meant for other modules, export it.
