---
code: TS2305
summary: An import names something the module doesn't export. Check the spelling, or whether it is a default export.
---

## What it means

The module resolves, but it has no export with the imported name. Typical causes are a
typo, a renamed export, or importing a default export with braces.

## Example

```ts example file=math.ts
export function add(a: number, b: number) {
  return a + b;
}
```

```ts example
import { sum } from "./math";

export const three = sum(1, 2);
```

## How to fix

- Use the name the module actually exports.
- For a default export, import without braces: `import add from "./math"`.
