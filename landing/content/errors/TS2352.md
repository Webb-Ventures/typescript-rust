---
code: TS2352
summary: A type assertion (`as`) converts between two types that don't overlap at all, which is probably a mistake. Fix the value, or go through `unknown`.
---

## What it means

`x as T` is allowed when either type is assignable to the other. When the two types have
nothing in common, the assertion is almost certainly wrong, so it's reported.

## Example

```ts example
const id = 42;

export const s = id as string;
```

## How to fix

- Convert the value instead: `String(id)`.
- If you really mean it, assert through `unknown`: `id as unknown as string`. That tells the
  checker to trust you; nothing checks it at runtime.
