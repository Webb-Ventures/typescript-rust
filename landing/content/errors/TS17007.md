---
code: TS17007
summary: A type assertion `<T>x` is on the left of `**`. Add parentheses around it.
---

## What it means

An angle-bracket type assertion (`<number>x`) directly on the left-hand side of `**` isn't
allowed, for the same reason as unary operators ([TS17006](TS17006.md)). ts-r's parser reports
it.

## Example

```ts example
declare const x: unknown;
export const y = <number>x ** 2;
```

## How to fix

- Wrap the assertion in parentheses: `(<number>x) ** 2`, or use `as`: `(x as number) ** 2`.
