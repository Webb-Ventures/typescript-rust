---
code: TS1044
summary: A class-member modifier such as `public` or `static` is used on a declaration inside a namespace or module. Remove it, or use `export`.
---

## What it means

Inside a `namespace` (or `module`) block, declarations are either exported or local. Class
modifiers such as `public`, `private`, `protected` and `static` don't apply there.

## Example

```ts example
export namespace App {
  public const version = 1;
}
```

## How to fix

- To make the declaration visible outside the namespace, use `export const version = 1`.
- Otherwise delete the modifier.
