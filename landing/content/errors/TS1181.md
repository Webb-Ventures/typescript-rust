---
code: TS1181
summary: An array destructuring pattern contains something that cannot be a binding target, such as a reserved word.
---

## What it means

Each element of an array destructuring pattern must be a name, a nested pattern, a hole
(`,`) or a `...rest` element. A reserved word such as `debugger` or `if` ends the pattern here,
so other syntax errors usually follow.

## Example

```ts example
const [debugger] = [1];
export {};
```

## How to fix

- Use a valid variable name in the pattern: `const [first] = [1];`.
