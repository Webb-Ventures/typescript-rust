## What it means

`declare const`, `declare function`, `declare class`, `declare enum` and `declare namespace` in a sound `.ts` file tell the checker a value exists at runtime without proving it. It's reported at the declaration name.

## Example

```ts spec
// declare const in a sound file asserts a value exists.
declare const API_URL: string; // @expect TSR1103
export const url: string = API_URL;
```

## How to fix

- Import the real value instead.
- Or move the declaration into one project `.d.ts` file (for example `types/ambient.d.ts`).

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
