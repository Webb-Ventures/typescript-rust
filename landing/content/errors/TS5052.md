---
code: TS5052
summary: A compiler option is set that only works together with another option, which is missing. Set the other option, or remove this one.
---

## What it means

Some options depend on others. The option named first in the message is set in `tsconfig.json`
but the option it needs isn't. `ts_r_config` detects this, but ts-r-check doesn't print program-level option checks yet, so
running it on such a config shows no error today.

## How to fix

- Set the option the message names as required, or remove the dependent option.
