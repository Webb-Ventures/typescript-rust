---
code: TS2593
summary: A test runner global such as describe or it isn't known. Install your test runner's type definitions and add them to types.
---

## What it means

The name is a global that test runners define (`describe`, `it`, `test` and similar), and no type
definitions for one are loaded.

## Example

```ts example
describe("math", () => {});
export {};
```

## How to fix

- Install the types for your runner, for example `npm i --save-dev @types/jest` or `@types/mocha`, and add it to `types` if `tsconfig.json` sets that option.
- With runners that export these functions (Vitest, `node:test`), import them: `import { describe, it } from "vitest"`.
