---
code: TS1028
summary: A class member or parameter property has two accessibility modifiers (`public`, `private` or `protected`). Keep only one.
---

## What it means

A member can have at most one of `public`, `private` and `protected`. Writing two, even the
same one twice, is an error. It's reported on the second modifier, for class members and for
constructor parameter properties.

## Example

```ts example
export class User {
  public private name = "";
}
```

## How to fix

- Delete one of the modifiers and keep the visibility you mean.
- Members are `public` by default, so `public` can usually be dropped.
