## What it means

A file's level pragma is read only from the leading comments, before the first statement. A pragma further down is ignored, and this diagnostic says so.

## Example

```ts spec
// The pragma has to come before the first statement.
export const n: number = 1;
// @ts-r off // @expect TSR0005
```

## How to fix

- Move the pragma to the top of the file, above the imports.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
