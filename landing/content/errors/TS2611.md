---
code: TS2611
summary: A subclass declares a getter/setter where the base class has a plain property. Use a property in the subclass too, or rename it.
---

## What it means

The base class declares the member as an ordinary property and a subclass redeclares it as an
accessor. The base class's field is created on each instance and hides the subclass's accessor.

## Example

```ts example
class Base {
  size = 1;
}
class Child extends Base {
  get size(): number { return 2; }
}
export {};
```

## How to fix

- Keep it a property in the subclass, and set it in the constructor if it needs a different value.
- Or make it an accessor in the base class as well.
- Or rename one of the two members.
