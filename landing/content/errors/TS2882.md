---
code: TS2882
summary: A side-effect import (import "x") names a module that can't be resolved. Fix the path or install the package.
---

## What it means

An `import "x"` statement with no bindings still has to resolve to a module. The module couldn't
be found, either as a file or a package.

## Example

```ts example
import "./missing-setup";
export {};
```

## How to fix

- Fix the path or the package name.
- Install the package if it's missing.
- For non-code imports such as CSS, declare them in a `.d.ts`, for example `declare module "*.css";`.
