## What it means

This is the excess property check ([TS2353](TS2353.md)) with a suggestion: the object literal
has a property that the target type doesn't have, and a property with a close spelling exists.

## Example

```ts example
interface User {
  firstName: string;
}
export const u: User = { firstname: "Ada" };
```

## How to fix

- Use the suggested property name.
- If the property should be allowed, add it to the type.
