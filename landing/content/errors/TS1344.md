---
code: TS1344
summary: A label is placed before a declaration or other statement that can't be labelled. Remove the label.
---

## What it means

Labels exist for `break` and `continue`. In strict code a label can't be put in front of a
function declaration, and a few other positions don't allow one either.

## Example

```ts example
export {};
outer: function run() {}
```

## How to fix

- Remove the label. Labels only make sense on loops and blocks you `break` out of.
