---
code: TS1131
summary: Inside an interface or type literal, the parser expected a property or signature but found another token.
---

## What it means

Interface bodies and object type literals contain property signatures (`x: number`), method
signatures, call and construct signatures, and index signatures. Anything else is reported
here, such as an `=` initialiser (types can't have values) or stray punctuation.

## Example

```ts example
export type P = {
  x: number;
  =
};
```

## How to fix

- Remove the stray token.
- Types can't hold values: move default values to the code that creates objects of this type.
