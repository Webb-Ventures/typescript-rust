## What it means

Values from outside the program (`JSON.parse`, `.json()` on `Response`, `MessageEvent.data`, server request bodies) are typed `unknown` in sound files until parsed. They may be stored as `unknown` and narrowed with `typeof`, `instanceof`, `in` and equality checks; any other use (property access, a call, assignment to a typed target, a typed return, spread, destructuring or a type assertion) is reported.

## Example

```ts spec
// Destructuring an external value reads properties off it.
const { theme } = JSON.parse('{"theme":"dark"}'); // @expect TSR1401
export const t: unknown = theme;
```

## How to fix

- Validate it: `const user = parse<User>(JSON.parse(text))`, or `fetchJson<User>(url)`.
- Use `safeParse<T>` to get a result instead of an exception.
- Keep it `unknown` and narrow it by hand.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
