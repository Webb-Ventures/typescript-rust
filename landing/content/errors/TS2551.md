---
code: TS2551
summary: A property that doesn't exist is accessed, and a similarly named one does. Usually a typo: use the suggested name.
---

## What it means

This is [TS2339](TS2339.md) with a suggestion: the property doesn't exist on the type, but one
with a close spelling does, and the message names it.

## Example

```ts example
const user = { firstName: "Ada" };
export const n = user.firstname;
```

## How to fix

- Use the suggested property name if it's what you meant.
- If the property should exist, add it to the type.
