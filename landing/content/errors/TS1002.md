---
code: TS1002
summary: A string literal has no closing quote before the end of the line. Add the missing quote, or use a template literal for multi-line text.
---

## What it means

A string written with `'` or `"` must end on the same line it starts on. The parser reached
the end of the line (or the file) without finding the closing quote. The rest of the line is
read as part of the string, so other errors often follow on the next lines.

## Example

```ts example
const greeting = "hello;
export {};
```

## How to fix

- Add the closing quote that matches the opening one.
- For text that spans lines, use a template literal (`` `...` ``) or join strings with `+`.
- A backslash before the quote (`\"`) escapes it; remove the backslash if the quote is meant to end the string.
