---
code: TS2357
summary: `++` or `--` is applied to something that isn't a variable or property, such as a call or a literal. Assign to a variable instead.
---

## What it means

Increment and decrement change their operand, so the operand must be something that can be
assigned to: a variable, a property or an element access.

## Example

```ts example
function count(): number {
  return 1;
}

count()++;
```

## How to fix

- Store the value in a variable and increment that.
