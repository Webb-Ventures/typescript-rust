## What it means

`void p` hides a promise from the type checker but not its rejection. In sound and strict files `void` is allowed only on a handled chain.

## Example

```ts spec
// void hides the promise but not its rejection.
async function save(x: string): Promise<void> {
  console.log(x);
}
void save("a"); // @expect TSR1002
export {};
```

## How to fix

- Handle the rejection before discarding: `void save(user).catch(report)`.
- Or `await` the promise.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
