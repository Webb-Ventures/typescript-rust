---
code: TS5061
summary: A key in the paths option has more than one * wildcard. Use at most one * per pattern.
---

## What it means

In `compilerOptions.paths`, each key is a module-name pattern that may contain one `*`. A key with
two or more is invalid.

## Example

```json tsconfig
{ "compilerOptions": { "paths": { "@app/*/*": ["./src/*"] } } }
```

```ts example
export const x = 1;
```

## How to fix

- Rewrite the pattern with a single `*`, for example `"@app/*": ["src/*"]`.
