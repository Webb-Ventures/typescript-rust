---
code: TS5102
summary: tsconfig.json sets an option that TypeScript 7 removed, such as `baseUrl`, `outFile` or `downlevelIteration`. Delete it.
---

## What it means

Some compiler options no longer exist in TypeScript 7, and tsc 7 reports
`baseUrl`, `outFile` and `downlevelIteration` when they are set. For `baseUrl` the error has
related information suggesting a `paths` entry that keeps the same lookups working.

ts-r's config loader has this check, but `ts-r-check` doesn't print program-level option
diagnostics yet, so it doesn't report this code today. tsc 7 does.

## How to fix

- Remove the option from `tsconfig.json` (and from any config it `extends`).
- For `baseUrl`, add `"paths": { "*": ["./*"] }` if code relied on bare imports resolving from
  the project root.
- For `outFile`, use a bundler such as `ts-r-build`.
