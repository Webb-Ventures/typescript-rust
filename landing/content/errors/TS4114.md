---
code: TS4114
summary: Under noImplicitOverride, a member replaces a base class member without the override keyword. Add override.
---

## What it means

With `noImplicitOverride` on, every member that replaces a base class member must say so with
`override`. That way, renaming or removing the base member makes the subclass fail to compile
instead of silently becoming a new member.

## Example

```json tsconfig
{ "compilerOptions": { "noImplicitOverride": true } }
```

```ts example
class Base {
  start() {}
}
class Child extends Base {
  start() {}
}
export {};
```

## How to fix

- Add `override`: `override start() {}`.
