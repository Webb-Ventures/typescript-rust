---
code: TS1199
summary: A `\u{...}` escape has no closing brace. Close the brace after the hex digits.
---

## What it means

A Unicode code point escape is written `\u{` hex digits `}`. This is reported when the
closing `}` is missing.

## Example

```ts example
const s = "\u{1F600 x";
export {};
```

## How to fix

- Close the escape: `"\u{1F600} x"`.
