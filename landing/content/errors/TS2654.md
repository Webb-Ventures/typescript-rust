---
code: TS2654
summary: A class extends an abstract class without implementing all of its abstract members. Implement them, or mark the subclass abstract.
---

## What it means

The base class has `abstract` members, and a concrete (non-abstract) subclass doesn't provide some
of them. The message lists the missing members. With only one missing member, the checker uses
TS2515 instead.

## Example

```ts example
abstract class Shape {
  abstract area(): number;
  abstract name(): string;
}
class Square extends Shape {}
export {};
```

## How to fix

- Implement every listed member in the subclass.
- Or mark the subclass `abstract` and implement them further down.
