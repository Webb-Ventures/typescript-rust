## What it means

An `async` function, or any function returning a promise, may not be passed where the parameter's type returns `void`: the callee ignores the returned promise, so rejections are lost. `items.forEach(async ...)` is the common case. It's reported at the function argument.

## Example

```ts spec
// forEach ignores the promises its callback returns.
async function save(x: string): Promise<void> {
  console.log(x);
}
const items: string[] = ["a", "b"];
items.forEach(async (i) => { await save(i); }); // @expect TSR1003
export {};
```

## How to fix

- Use `for...of` with `await` inside an async function.
- Or map to promises and wait for them: `await Promise.all(items.map(async (i) => save(i)))`.
- Or handle errors inside a non-async callback: `items.forEach((i) => { save(i).catch(report); })`.
