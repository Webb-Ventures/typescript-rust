---
code: TS1068
summary: The parser found a token inside a class body that cannot start a member. Remove the stray token or move statements into a method.
---

## What it means

A class body may only contain members: a constructor, methods, accessors, properties, index
signatures and `static` blocks. Anything else, such as a stray `,` or `=>`, is reported here.
Commas between members are a common cause, since members are separated by `;` or new lines,
not commas.

## Example

```ts example
export class Counter {
  count = 0;
  ,
}
```

## How to fix

- Remove the stray token.
- Separate members with semicolons or line breaks, not commas.
- Move statements (calls, `if`, loops) into a method, the constructor or a `static` block.
