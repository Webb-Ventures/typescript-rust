---
code: TS99002
summary: The file is larger than 4 GiB, which ts-r can't parse because it stores positions as 32-bit offsets. Split the file.
---

## What it means

This is a ts-r code; tsc doesn't have it. ts-r stores positions in source files as 32-bit byte
offsets, so a file over 4 GiB can't be represented. The file is reported instead of being
parsed.

## How to fix

- Split the file, or exclude it from the project if it's data rather than code.
