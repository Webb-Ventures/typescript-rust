---
code: TS4113
summary: A member is marked override but the base class has no member with that name. Fix the name or remove override.
---

## What it means

`override` says the member replaces one from the base class, but the base class doesn't declare
a member of that name. Often the name is misspelled or the base member was renamed.

## Example

```ts example
class Base {
  start() {}
}
class Child extends Base {
  override stop() {}
}
export {};
```

## How to fix

- Correct the name to match the base class member.
- Remove `override` if this is a new member.
