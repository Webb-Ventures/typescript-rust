---
code: TS2511
summary: new is used on an abstract class. Instantiate a concrete subclass instead.
---

## What it means

An abstract class can have members without implementations, so it can't be constructed
directly. Only non-abstract subclasses can be created with `new`.

## Example

```ts example
abstract class Shape {
  abstract area(): number;
}
export const s = new Shape();
```

## How to fix

- Create an instance of a concrete subclass that implements the abstract members.
- Remove `abstract` from the class if it is complete and meant to be instantiated.
