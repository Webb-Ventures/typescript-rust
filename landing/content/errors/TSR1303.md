## What it means

Only `Error` instances may be thrown or passed to `Promise.reject` in sound files, so catch blocks can rely on `message` and `stack`. Re-throwing the catch variable is allowed. It's reported at the thrown or rejected expression.

## Example

```ts spec
// Only Error objects may be thrown.
function fail(reason: string): never {
  throw "failed: " + reason; // @expect TSR1303
}
export const n: number = Math.random() > 2 ? fail("x") : 1;
```

## How to fix

- Throw an `Error` or a subclass: `throw new Error("failed: " + reason)`.
- Use `Promise.reject(new Error(...))` for rejections.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
