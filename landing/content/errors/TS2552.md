---
code: TS2552
summary: A name that isn't declared is used, and a similarly named one is in scope. Usually a typo: use the suggested name.
---

## What it means

This is [TS2304](TS2304.md) with a suggestion: no variable, function or type with this name is in
scope, but one with a close spelling is.

## Example

```ts example
const userName = "ada";
export const greeting = "hi " + username;
```

## How to fix

- Use the suggested name if it's what you meant.
- Otherwise declare or import the name.
