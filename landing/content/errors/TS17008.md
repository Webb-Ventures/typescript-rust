---
code: TS17008
summary: A JSX element is opened but never closed. Add its closing tag, or make it self-closing.
---

## What it means

ts-r's parser reached the end of the enclosing JSX (or the file) without finding the closing
tag for an element. It's reported at the opening tag.

## Example

```tsx example
export const el = <div><span>text</div>;
```

## How to fix

- Add the missing closing tag: `<span>text</span>`.
- Use a self-closing tag for elements without children: `<br />`.
