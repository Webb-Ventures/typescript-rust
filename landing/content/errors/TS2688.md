---
code: TS2688
summary: A types entry or /// <reference types> names a package whose type definitions can't be found. Install it or remove the entry.
---

## What it means

The name comes from the `types` option in `tsconfig.json` or a `/// <reference types="..." />`
comment, and no matching type definitions were found (usually in `node_modules/@types`).

## Example

```json tsconfig
{ "compilerOptions": { "types": ["not-installed"] } }
```

```ts example
export const x = 1;
```

## How to fix

- Install the definitions, for example `npm i --save-dev @types/<name>`.
- Fix the spelling of the entry.
- Remove the entry if the project no longer uses that package.
