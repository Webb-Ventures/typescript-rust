---
code: TS2769
summary: A call matches none of the function's overloads. Read the per-overload errors in the message and fix the arguments.
---

## What it means

The function has several overload signatures and the arguments don't fit any of them. The message
then lists, for each overload, why it didn't match.

## Example

```ts example
function parse(x: string): number;
function parse(x: number): string;
function parse(x: string | number): string | number { return x; }
parse(true);
export {};
```

## How to fix

- Read the indented lines: each one says why a particular overload was rejected.
- Change the arguments to match the overload you intended.
- If the call should be allowed, add an overload for it.
