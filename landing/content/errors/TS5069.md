---
code: TS5069
summary: An option is set that needs one of two other options, and neither is set. Enable one of them, or remove this option.
---

## What it means

The option named first only works when one of the two other options in the message is also set
in `tsconfig.json`. `ts_r_config` detects this, but ts-r-check doesn't print program-level option checks yet, so
running it on such a config shows no error today.

## How to fix

- Enable one of the two options the message names (for example `declaration`).
- Or remove the dependent option.
