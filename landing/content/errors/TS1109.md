---
code: TS1109
summary: The parser expected an expression (a value) here, but found an operator, a closing bracket or the end of the statement.
---

## What it means

An expression is required here: after a binary operator, after `=`, inside parentheses or in
a `return` with a value. Usually the code is unfinished, or an operator is doubled.

## Example

```ts example
const total = 1 + ;
export {};
```

## How to fix

- Complete the expression: `const total = 1 + 2;`.
- Remove the extra operator or punctuation.
