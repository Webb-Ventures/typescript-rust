---
code: TS2576
summary: An instance is used to read a static member. Read it through the class name instead, as ClassName.member.
---

## What it means

Static members belong to the class itself, not to its instances. Reading one through an
instance (or through `this` in an instance method) finds nothing, and the message points to the
static member with the same name.

## Example

```ts example
class Counter {
  static max = 10;
}
const c = new Counter();
c.max;
export {};
```

## How to fix

- Read the member through the class: `Counter.max`.
- If each instance needs its own value, make it an instance property instead of `static`.
