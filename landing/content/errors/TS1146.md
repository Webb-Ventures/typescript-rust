---
code: TS1146
summary: The parser expected a declaration here, for example after `export` or a decorator, but found something else.
---

## What it means

Some keywords must be followed by a declaration: `export` (unless it's `export { ... }` or
`export default`), `declare`, and decorators. This is reported when the next token can't start
one.

## Example

```ts example
export namespace N { export 1 }
```

## How to fix

- Complete the declaration: `export const one = 1`.
- Remove the stray `export`, `declare` or decorator.
