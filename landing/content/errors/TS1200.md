---
code: TS1200
summary: An arrow function has a line break between its parameters and `=>`. Keep `=>` on the same line as the closing parenthesis.
---

## What it means

JavaScript doesn't allow a line break before `=>`. The parameter list and the arrow must be on
the same line; the body can start on the next line.

## Example

```ts example
const double = (n: number)
  => n * 2;
export {};
```

## How to fix

- Move `=>` up: `const double = (n: number) =>` followed by the body on the next line.
