---
code: TS1097
summary: A list such as an `implements` or `extends` clause is empty. Name at least one type, or remove the keyword.
---

## What it means

Keywords that introduce a list, such as `implements` or `extends`, need at least one entry
after them. The message names which list is empty.

## Example

```ts example
export class Shape implements {}
```

## How to fix

- Name the interface: `class Shape implements Drawable {}`.
- If the class implements nothing, remove the `implements` keyword.
