---
code: TS1160
summary: A template literal (backtick string) has no closing backtick before the end of the file. Add the missing backtick.
---

## What it means

Template literals can span lines, so a missing closing backtick makes the rest of the file part
of the string. The error is reported where the file ends.

## Example

```ts example
const msg = `hello ${name}
export {};
```

## How to fix

- Add the closing backtick where the string should end.
- Look for a backtick inside the text that should be escaped as `` \` ``.
