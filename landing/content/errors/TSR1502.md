## What it means

Validators are generated from declarations at build time, so inside generic code `parse<T>` has no concrete type to validate.

## Example

```ts spec
// parse<T> inside generic code has no concrete type to validate.
import { parse } from "@ts-r.dev/guard";

function load<T>(raw: unknown): T {
  return parse<T>(raw); // @expect TSR1502
}
export const n: number = load<number>(1);
```

## How to fix

- Take a `Guard<T>` parameter and call its `parse`; at the call site pass `guard<User>()`.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
