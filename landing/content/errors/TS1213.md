---
code: TS1213
summary: A word reserved in strict mode (such as `private` or `static`) is used as a name inside a class. Classes are always strict. Rename it.
---

## What it means

Class bodies are always strict-mode code, so the strict-mode reserved words (`implements`,
`interface`, `let`, `package`, `private`, `protected`, `public`, `static`, `yield`) can't be
used as names of variables or parameters inside them.

## Example

```ts example
class A {
  m() {
    let private = 1;
  }
}
```

## How to fix

- Rename the variable or parameter, for example `isPrivate`.
