---
code: TS1114
summary: Two nested statements use the same label. Give the inner one a different label.
---

## What it means

A label names a loop or block so `break` and `continue` can target it. A label can't be
reused for a statement nested inside another statement with the same label, since `break
outer` would be ambiguous.

## Example

```ts example
outer: for (;;) {
  outer: for (;;) { break outer; }
}
export {};
```

## How to fix

- Rename the inner label (`inner:`) and update the `break` or `continue` statements that use it.
