---
code: TS1118
summary: An object literal has two getters (or two setters) for the same property. Keep one of each.
---

## What it means

A property can have at most one `get` and one `set` accessor in an object literal. A second
getter or setter with the same name is reported here; `ts-r-check` also reports
[TS2300](TS2300.md) on both declarations.

## Example

```ts example
const o = {
  get a() { return 1; },
  get a() { return 2; },
};
export {};
```

## How to fix

- Delete one of the duplicate accessors.
- A getter and a setter for the same name together are fine.
