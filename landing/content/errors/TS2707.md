---
code: TS2707
summary: A generic type gets too few or too many type arguments for its optional type parameters. Pass a count within the stated range.
---

## What it means

The generic type has some type parameters with defaults, so it accepts a range of type argument
counts. The reference passes a count outside that range.

## Example

```ts example
type Pair<A, B = A> = [A, B];
let p: Pair<string, number, boolean>;
export {};
```

## How to fix

- Pass between the minimum and maximum number of type arguments shown in the message.
