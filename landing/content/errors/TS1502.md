---
code: TS1502
summary: A regular expression literal has both the `u` and `v` flags. Keep one; `v` includes everything `u` does.
---

## What it means

The `v` (Unicode Sets) flag is an extended form of `u`, and the two can't be set together.

## Example

```ts example
export const re = /[a-z]/uv;
```

## How to fix

- Use `v` alone if you need set operations, otherwise `u` alone.
