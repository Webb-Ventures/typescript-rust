---
code: TS17006
summary: A unary operator like `-x` is on the left of `**`. Add parentheses: `(-x) ** 2`.
---

## What it means

JavaScript doesn't allow a unary operator (`-`, `+`, `!`, `~`, `typeof`, `void`, `delete`,
`await`) directly on the left-hand side of `**`, because `-2 ** 2` would be ambiguous. ts-r's
parser reports it; the message names the operator.

## Example

```ts example
declare const x: number;
export const y = -x ** 2;
```

## How to fix

- Add parentheses for the meaning you want: `(-x) ** 2` or `-(x ** 2)`.
