code: TS99003

---

## What it means

This is a ts-r code; tsc doesn't have it. Every loop in ts-r's parser must consume input or
stop. If error recovery ever stops advancing, the parser reports this and skips the rest of the
file rather than looping forever. It indicates a parser bug, usually triggered by unusual
malformed input.

## How to fix

- Fix any syntax errors reported before it in the same file; that often avoids it.
- Report the file (or a minimal part of it) as a ts-r bug.
