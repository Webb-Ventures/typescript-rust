---
code: TS7009
summary: `new` is used on a value that has no construct signature, so the result would be `any`. Call a class, or type the value as a constructor.
---

## What it means

Under `noImplicitAny`, calling `new` on something whose type has no construct signature (for
example a plain function type) produces an implicit `any`. In TypeScript files only classes
and values typed with `new (...) => T` can be constructed.

## Example

```ts example
declare const makeUser: (name: string) => { name: string };
export const u = new makeUser("ada");
```

## How to fix

- Call it without `new` if it's a plain function: `makeUser("ada")`.
- Turn it into a class, or give it a construct signature in its type:
  `declare const User: new (name: string) => { name: string }`.
