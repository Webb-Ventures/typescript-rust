---
code: TS1212
summary: A word reserved in strict mode (such as `interface`, `package` or `private`) is used as a name in strict-mode code. Rename it.
---

## What it means

In strict mode some extra words are reserved: `implements`, `interface`, `let`, `package`,
`private`, `protected`, `public`, `static` and `yield`. They can't be used as variable,
function or parameter names. This code is for scripts with `"use strict"`; modules and classes
report [TS1214](TS1214.md) and [TS1213](TS1213.md).

## Example

```ts example
"use strict";
var interface = 1;
```

## How to fix

- Rename the binding, for example `iface`.
