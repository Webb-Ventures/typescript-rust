---
code: TS2420
summary: A class says it implements an interface but is missing a member or has one with the wrong type. Add or fix the member named in the indented lines.
---

## What it means

`implements` asks the checker to compare the class's instance type with the interface. A missing
member, or one with an incompatible type, is reported on the class name with indented lines
that explain which member is wrong.

## Example

```ts example
interface Named {
  name: string;
}
export class Robot implements Named {
  id = 1;
}
```

## How to fix

- Add the missing members the indented lines list.
- Fix members whose types don't match the interface.
- Remove the `implements` clause if the class isn't meant to satisfy the interface.
