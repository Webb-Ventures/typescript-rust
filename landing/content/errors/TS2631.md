---
code: TS2631
summary: A namespace name is used as an assignment target. Namespaces can't be reassigned; change their members instead.
---

## What it means

The left side of the assignment is a namespace. A namespace's name can't be rebound.

## Example

```ts example
namespace Config { export const debug = false; }
Config = Config;
export {};
```

## How to fix

- Change members of the namespace instead, or use an object in a `let` variable if the whole value needs replacing.
