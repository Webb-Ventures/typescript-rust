---
code: TS2411
summary: A property doesn't fit the type of an index signature in the same type. Change the property's type, or widen the index signature.
---

## What it means

An index signature like `[key: string]: number` says every string-named property has that type,
including the ones declared explicitly. A named property whose type isn't assignable to the
index signature's type breaks that promise.

## Example

```ts example
export interface Scores {
  [name: string]: number;
  label: string;
}
```

## How to fix

- Widen the index signature: `[name: string]: number | string`.
- Or move the odd property out: `{ label: string; scores: Record<string, number> }`.
