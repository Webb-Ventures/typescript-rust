## What it means

`@ts-nocheck` switches off all checking for a file. In a sound file it's an error; lowering the file's sound-mode level is done with the `// @ts-r` pragma.

## Example

```ts spec
// @ts-nocheck // @expect TSR1202
// The nocheck directive can't switch checking off in a sound file.
export const n: number = 1;
```

## How to fix

- Replace it with `// @ts-r off` (or `// @ts-r strict`) to lower the file's level.
- Or remove it and fix the errors.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
