---
code: TS1141
summary: A string literal is required here, for example as the module name in `import ... from`. Quote the name.
---

## What it means

Some places only accept a string literal: the module specifier of `import`, `export ... from`
and `import(...)` types, and the name in `declare module "name"`. A bare identifier or number
there is reported.

## Example

```ts example
import x from 123;
export {};
```

## How to fix

- Write the module name as a string: `import x from "./x";`.
