---
code: TS1117
summary: An object literal defines the same property name twice. Remove one of them or rename it.
---

## What it means

In an object literal, a second property with the same name silently overwrites the first at
runtime, which is almost always a mistake, so it's reported on the second one.

## Example

```ts example
const o = { a: 1, a: 2 };
export {};
```

## How to fix

- Delete the duplicate property, keeping the value you mean.
- If both values are needed, give them different names.
