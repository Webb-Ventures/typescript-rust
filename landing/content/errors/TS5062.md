---
code: TS5062
summary: A substitution in the paths option has more than one * wildcard. Use at most one * in each target path.
---

## What it means

In `compilerOptions.paths`, each target path in a pattern's array may contain at most one `*`,
which receives what the key's `*` matched.

## Example

```json tsconfig
{ "compilerOptions": { "paths": { "@app/*": ["./src/*/*"] } } }
```

```ts example
export const x = 1;
```

## How to fix

- Use a single `*` in each substitution: `"@app/*": ["src/*"]`.
