---
code: TS1125
summary: A hexadecimal number or escape has no hex digits where they are required, as in `0x` alone. Add the digits.
---

## What it means

Hexadecimal literals (`0x...`) and escapes such as `\x..` and `\u....` need hexadecimal
digits (`0-9`, `a-f`, `A-F`). This is reported when none or too few follow.

## Example

```ts example
const n = 0x;
export {};
```

## How to fix

- Write the digits: `0xff`.
- In strings, a `\u` escape needs exactly four hex digits, or braces: `\u{1F600}`.
