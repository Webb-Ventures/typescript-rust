---
code: TS1090
summary: A modifier that is not allowed on parameters, such as `export`, is used on a function or constructor parameter. Remove it.
---

## What it means

Parameters accept only a few modifiers, and only in a constructor: `public`, `private`,
`protected`, `readonly` and `override` turn the parameter into a class property. Other modifiers
such as `export` are reported here.

## Example

```ts example
export class A {
  constructor(export name: string) {}
}
```

## How to fix

- Delete the modifier.
- To declare a property from a constructor parameter, use `public`, `private`, `protected` or `readonly`.
