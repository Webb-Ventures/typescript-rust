---
code: TS17002
summary: A JSX closing tag doesn't match the opening tag it closes. Make the names match.
---

## What it means

In JSX every element must be closed by a tag with the same name. When the closing tag names a
different element, ts-r's parser reports this at the closing tag, naming the element it
expected.

## Example

```tsx example
export const el = <div>text</span>;
```

## How to fix

- Change the closing tag to match the opening one, or fix the nesting so each element closes
  in order.
