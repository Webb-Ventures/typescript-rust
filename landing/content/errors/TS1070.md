---
code: TS1070
summary: A modifier such as `public` or `static` is used on a member of an interface or type literal. Type members cannot have these modifiers.
---

## What it means

Interfaces and type literals describe shapes; their members have no visibility and are never
static. Of the modifiers, only `readonly` is allowed on a type member. Accessibility, `static`,
`abstract`, `async`, `export`, `declare` and `override` are reported here.

## Example

```ts example
export interface Point {
  public x: number;
}
```

## How to fix

- Delete the modifier: `x: number`.
- If you need `private` or `static` members, use a class.
