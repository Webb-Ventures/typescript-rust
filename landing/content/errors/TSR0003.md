## What it means

`// @ts-r-unsafe S-02 S-03: <reason>` limits a hatch to the listed rules. A rule id outside S-01 to S-14 is an error, and the hatch suppresses nothing.

## Example

```ts spec
// Rule ids are S-01 to S-14.
// @ts-r-unsafe S-99: no such rule. // @expect TSR0003
const n: number = 1;
export { n };
```

## How to fix

- Use the rule id from the diagnostic you want to suppress (each TSR code belongs to one rule: TSR02xx is S-02, TSR14xx is S-14).
- Or drop the rule list so the hatch covers every sound-mode rule on the next line.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
