---
code: TS2469
summary: An arithmetic or comparison operator is applied to a symbol. Symbols can't be converted to numbers; use the symbol's description or compare with ===.
---

## What it means

Symbols throw a `TypeError` when converted to a number or string implicitly. Operators like `+`,
`-`, `<` or unary `+` on a value of type `symbol` are reported.

## Example

```ts example
const tag = Symbol("tag");
export const n = +tag;
```

## How to fix

- Use `tag.description` or `String(tag)` if you need text.
- Compare symbols with `===`, which works without conversion.
