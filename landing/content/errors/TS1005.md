---
code: TS1005
summary: The parser expected a specific token (shown in quotes in the message) and found something else. Usually a missing comma, bracket or semicolon.
---

## What it means

The message names the exact token the parser needed, such as `','`, `')'`, `';'` or `'}'`.
It's reported at the place where that token should have been. A missing token earlier in the
file can make the parser report this at a later, surprising spot, and one mistake can produce
several of these errors in a row: fix the first one first.

## Example

```ts example
const point = { x: 1 y: 2 };
export {};
```

## How to fix

- Insert the token the message names at the reported position (here a `,` between properties).
- Check that brackets, parentheses and braces are balanced above the reported line.
- Fix the first syntax error in the file and re-run; later ones are often caused by it.
