## What it means

`declare module "x";` without a body types every import from `x` as `any`. In a sound file that is reported at the module name.

## Example

```ts spec
// A script file (no imports or exports, on purpose) declaring a wildcard shorthand module.
declare module "tsr-fixture-assets-*"; // @expect TSR1102
```

## How to fix

- Declare the module's real types in a `.d.ts` file.
- Move the shorthand declaration to a `.d.ts` file if you accept the untyped boundary; the package is then treated as `loose` and listed in the report.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
