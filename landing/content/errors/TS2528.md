---
code: TS2528
summary: A module has more than one default export. Keep one export default and turn the others into named exports.
---

## What it means

A module has a single `default` export. Two `export default` statements (or a default class and
a default function) in the same file are reported on each.

## Example

```ts example
const start = 1;
const stop = 2;
export default start;
export default stop;
```

## How to fix

- Keep one default export and make the others named: `export function stop() {}`.
- Or export a single object that holds both.
