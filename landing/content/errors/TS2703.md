---
code: TS2703
summary: delete is applied to something that isn't a property, such as a variable. Only properties can be deleted; set a variable to undefined instead.
---

## What it means

The `delete` operator removes a property from an object. Its operand must be a property access
such as `obj.key` or `obj[key]`.

## Example

```ts example
let value = 1;
delete (value + 1);
export {};
```

## How to fix

- Delete a property: `delete obj.key`.
- To clear a variable, assign `undefined` to it (and include `undefined` in its type).
