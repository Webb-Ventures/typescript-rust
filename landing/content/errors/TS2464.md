---
code: TS2464
summary: A computed property name has a type that can't be a property key. Use a string, number or symbol expression.
---

## What it means

Property keys in JavaScript are strings, numbers (converted to strings) or symbols. A computed
name `[expr]` in an object literal or class whose type is something else, such as an object or a
boolean, is reported.

## Example

```ts example
const key = { id: 1 };
export const table = { [key]: "row" };
```

## How to fix

- Use a string, number or symbol for the key: `[key.id]` or `[String(key.id)]`.
- If you need object keys, use a `Map` instead of an object literal.
