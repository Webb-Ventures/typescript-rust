---
code: TS2417
summary: The static side of a class doesn't fit the static side of its base class. Make overridden static members compatible with the base ones.
---

## What it means

A class constructor inherits the base constructor's static members. A static property or method
redeclared with an incompatible type breaks code that uses the subclass where the base class
constructor is expected.

## Example

```ts example
class Model {
  static table: string = "models";
}
export class User extends Model {
  static table: number = 1;
}
```

## How to fix

- Give the static member the same (or a compatible) type as in the base class.
- Rename it if it means something else in the subclass.
