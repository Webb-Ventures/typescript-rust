---
code: TS6189
summary: A number has two underscores in a row, like `1__000`. Use a single `_` between digit groups.
---

## What it means

Numeric separators must be single underscores between digits. Two or more in a row are a
syntax error, reported by ts-r's lexer.

## Example

```ts example
export const big = 1__000;
```

## How to fix

- Use one underscore: `1_000`.
