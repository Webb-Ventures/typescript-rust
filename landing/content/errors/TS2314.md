---
code: TS2314
summary: A generic type is used without the type arguments it requires, like `Map` instead of `Map<K, V>`. Add them.
---

## What it means

A generic type whose type parameters have no defaults needs type arguments every time it is
written as a type. The message says how many.

## Example

```ts example
type Box<T> = { value: T };

export const b: Box = { value: 1 };
```

## How to fix

- Add the type arguments: `Box<number>`.
- If most uses want the same type, give the parameter a default: `type Box<T = unknown>`.
