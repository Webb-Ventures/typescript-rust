---
code: TS2740
summary: A value is missing many properties of the target type; a few are listed and the rest counted. Usually the wrong kind of value is used.
---

## What it means

Like [TS2739](TS2739.md), but more than four properties are missing, so the message names a few
and counts the rest. A long list usually means a different kind of value was passed entirely,
such as an object where an array was expected.

## Example

```ts example
const list: string[] = {};
export {};
```

## How to fix

- Check that you're passing the kind of value the target expects (an array, a `Map`, an element).
- If the value really is a partial object, use `Partial<T>` or a narrower type for the target.
