---
code: TS1184
summary: Modifiers are used where none are allowed at all, for example `static` on a method in an object literal.
---

## What it means

Some positions accept no modifiers. `ts-r-check` reports this, for example, on the first
modifier of an object-literal method (other than `async`), together with
[TS1042](TS1042.md) for each modifier.

## Example

```ts example
export const o = { async static m() { return 1; } };
```

## How to fix

- Remove the modifiers. In object literals only `async` is allowed on methods.
