## What it means

Suppression comments hide type errors without saying why, so `@ts-ignore` and `@ts-expect-error` are errors in sound files. They still suppress, so the underlying error isn't reported twice.

## Example

```ts spec
// The ignore directive is not allowed in a sound file.
// @ts-ignore // @expect TSR1201
const n: number = 1;
export { n };
```

## How to fix

- Fix the tsc error the directive hides.
- For a sound-mode error, use `// @ts-r-unsafe: <reason>` instead (it only suppresses TSR codes).
- Planned: `ts-r-check --sound-report` will list each directive with the error it hides.

Sound mode is defined in [design record 0007](../../../docs/design/0007-sound-mode.md) (accepted 2026-10-15).
