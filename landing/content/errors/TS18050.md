---
code: TS18050
summary: The literal `null` or `undefined` is used where it can never work, such as `null.x` or `null + 1`.
---

## What it means

The value `null` (or `undefined`) is written directly in a position where it can only fail or
make no sense: accessing a property on it, calling it, or using it as an arithmetic operand.
The message names the value.

## Example

```ts example
export const n = null + 1;
```

## How to fix

- Replace the literal with the value you meant, or remove the expression.
