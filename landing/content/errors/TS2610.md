---
code: TS2610
summary: A subclass declares a plain property where the base class has a getter/setter. Override it with an accessor, or rename the property.
---

## What it means

A base class defines the member as an accessor (`get`/`set`) and a subclass redeclares it as an
ordinary instance property. With class fields, the subclass's field replaces the accessor on
each instance, so the base class's getter and setter would never run.

## Example

```ts example
class Base {
  get size(): number { return 1; }
}
class Child extends Base {
  size = 2;
}
export {};
```

## How to fix

- Override it with an accessor in the subclass: `get size() { return 2; }`.
- Or rename one of the two members.
