---
code: TS1030
summary: The same modifier is written twice on one declaration. Delete the repeated one.
---

## What it means

A modifier such as `readonly`, `static` or `abstract` can appear only once on a declaration.
It's reported on the second occurrence. Repeated accessibility modifiers are reported as
[TS1028](TS1028.md) instead.

## Example

```ts example
export class User {
  readonly readonly id = 1;
}
```

## How to fix

- Remove the duplicate modifier.
