---
code: TS2555
summary: A function with optional or rest parameters is called with too few arguments. Pass at least the required ones.
---

## What it means

Like [TS2554](TS2554.md), but for functions whose parameter list doesn't have a fixed length (it
has optional or rest parameters), so the message gives the minimum instead of an exact count.

## Example

```ts example
function join(sep: string, first: string, ...rest: string[]): string {
  return [first, ...rest].join(sep);
}
export const s = join(",");
```

## How to fix

- Pass at least the required arguments.
- Make a parameter optional if callers may leave it out.
