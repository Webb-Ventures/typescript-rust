---
code: TS2389
summary: The implementation after a group of overload signatures has a different name. Rename it to match the overloads, or add the missing implementation.
---

## What it means

Overload signatures must be followed directly by the implementation with the same name. When
the next function declaration has another name, it can't implement the overloads.

## Example

```ts example
export function format(value: number): string;
export function formatValue(value: number): string {
  return value.toFixed(2);
}
```

## How to fix

- Give the implementation the same name as the overload signatures.
- If the overload was meant to be a separate function, give it a body.
